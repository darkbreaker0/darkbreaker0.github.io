## Code

<p style="color: var(--text-secondary);">Open research code, tools, and reproductions. GitHub: <a href="https://github.com/darkbreaker0">@darkbreaker0</a>.</p>

<div class="section-card" markdown="1">
### Research code & tools

- **[IJ_NeuriteGrowthScript](https://github.com/darkbreaker0/IJ_NeuriteGrowthScript)** · *ImageJ / Jython* — scripts for generating neurite-growth kymographs and quantitative growth profiling. Analysis code from the neuronal-polarization study (archived on Zenodo).
- **[Arp3_neuronal_polarization_2026](https://github.com/darkbreaker0/Arp3_neuronal_polarization_2026)** · *R / Python* — analysis pipeline behind the neuronal-polarization manuscript (archived on Zenodo).
- **[Correct_3D_drift_Clijx_GPU](https://github.com/darkbreaker0/Correct_3D_drift_Clijx_GPU)** · *Java / ImageJ* — a GPU-accelerated version of the ImageJ "Correct 3D drift" plugin, using a modified CLIJx with PhaseCorrelationFFT / VkFFT for fast registration of large image stacks.
</div>

<div class="section-card" markdown="1">
### Adaptations & re-implementations

These build on others' work and are credited accordingly.

- **[LEGI-gradient-sensing-simulation](https://github.com/darkbreaker0/LEGI-gradient-sensing-simulation)** · *Java (standalone)* — a modern, runnable standalone that revives the obsolete Java applet accompanying Kutscher, Devreotes & Iglesias, *"Local Excitation, Global Inhibition Mechanism for Gradient Sensing: An Interactive Applet,"* Science's STKE (2004), [doi:10.1126/stke.2192004pl3](https://doi.org/10.1126/stke.2192004pl3) — so the classic LEGI simulation runs again on today's machines.
- **[IJ-Plugin_KymoButler_for_ImageJ](https://github.com/darkbreaker0/IJ-Plugin_KymoButler_for_ImageJ)** · *Java / Fiji* — a fork of [F. Cordelières' plugin](https://github.com/fabricecordelieres/IJ-Plugin_KymoButler_for_ImageJ) that brings the KymoButler deep-learning kymograph analysis into ImageJ/Fiji.
- **[EphysExtraction](https://github.com/darkbreaker0/EphysExtraction)** · *Jupyter / Python* — extraction of electrophysiological parameters from neuronal recordings; adapted from the [Berens lab](https://github.com/berenslab/EphysExtraction).
</div>
